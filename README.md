# yizhao-jasper.github.io

Personal academic homepage of Yi Zhao, served via GitHub Pages at
[https://yizhao-jasper.github.io](https://yizhao-jasper.github.io).

Plain static site — no build step:

- `index.html` — single-page content (about, news, publications, experience, education, projects)
- `style.css` — minimal white academic style with blue accents
- `assets/portrait.jpg` — profile photo

To preview locally: `python3 -m http.server` in the repo root, then open `http://localhost:8000`.
